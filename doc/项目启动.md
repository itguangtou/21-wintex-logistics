# Wintex Logistics 项目启动指南

> 技术方案：**Supabase（数据库 + 图片存储）+ Vercel（部署）**  
> 不再使用 Redis / Upstash，所有内容通过管理端实时发布。

---

## 一、方案概述

| 组件 | 作用 | 费用 |
|------|------|------|
| **GitHub** | 代码仓库 | 免费 |
| **Supabase** | PostgreSQL 数据库 + 文件存储 | 免费版够用 |
| **Vercel** | 网站托管与自动部署 | 免费版够用 |
| **域名** | 自定义网站地址（可选） | 自备，约 ¥50–100/年 |

### 整体流程

```
1. GitHub 建仓
   ↓
2. Supabase 建库建表
   ↓
3. 改代码接 Supabase（去掉 Redis）
   ↓
4. 导入现有数据
   ↓
5. 本地测试
   ↓
6. Vercel 部署
   ↓
7. 配置环境变量
   ↓
8. 上线验证
```

**预计首次完成时间：** 1–2 天

## 五、Phase 2：Supabase 建项目 + 建表（约 30 分钟）

### 5.1 创建项目

1. 登录 [Supabase Dashboard](https://supabase.com/dashboard)
2. 点击 **New Project**
3. 填写：
   - **Name**：`wintex-logistics`
   - **Database Password**：设置强密码并保存
   - **Region**：`Southeast Asia (Singapore)`（离菲律宾较近）
4. 等待约 2 分钟创建完成

### 5.2 获取 API 密钥

进入 **Project Settings → API**，记录：

| Supabase 字段 | 环境变量名 |
|---------------|------------|
| Project URL | `NEXT_PUBLIC_SUPABASE_URL` |
| anon public key | `NEXT_PUBLIC_SUPABASE_ANON_KEY` |
| service_role key | `SUPABASE_SERVICE_ROLE_KEY`（仅服务端，勿暴露前端） |

### 5.3 执行建表 SQL

进入 **SQL Editor → New query**，执行以下 SQL：

```sql
-- 站点配置（联系信息、SEO 等）
CREATE TABLE site_settings (
  key TEXT PRIMARY KEY,
  value JSONB NOT NULL DEFAULT '{}',
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 页面内容块（首页、关于我们等）
CREATE TABLE page_sections (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  page_slug TEXT NOT NULL,
  section_key TEXT NOT NULL,
  content_zh JSONB DEFAULT '{}',
  content_en JSONB DEFAULT '{}',
  sort_order INT DEFAULT 0,
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(page_slug, section_key)
);

-- 新闻
CREATE TABLE news (
  id TEXT PRIMARY KEY,
  title_zh TEXT,
  title_en TEXT,
  content_zh TEXT,
  content_en TEXT,
  image_url TEXT,
  published_at DATE,
  sort_order INT DEFAULT 0,
  is_published BOOLEAN DEFAULT true,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 招聘（整包 JSON，兼容现有结构）
CREATE TABLE careers_data (
  id TEXT PRIMARY KEY DEFAULT 'main',
  data JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 装备清单
CREATE TABLE equipment (
  id SERIAL PRIMARY KEY,
  name_zh TEXT,
  name_en TEXT,
  description_zh TEXT,
  description_en TEXT,
  image_url TEXT,
  sort_order INT DEFAULT 0,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 使命页时间轴
CREATE TABLE timeline_items (
  id SERIAL PRIMARY KEY,
  year TEXT NOT NULL,
  project_name_zh TEXT,
  project_name_en TEXT,
  description_zh TEXT,
  description_en TEXT,
  parent_group INT,
  sort_order INT DEFAULT 0,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 自动更新 updated_at
CREATE OR REPLACE FUNCTION update_updated_at()
RETURNS TRIGGER AS $$
BEGIN NEW.updated_at = NOW(); RETURN NEW; END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER tr_site_settings BEFORE UPDATE ON site_settings
  FOR EACH ROW EXECUTE FUNCTION update_updated_at();
CREATE TRIGGER tr_page_sections BEFORE UPDATE ON page_sections
  FOR EACH ROW EXECUTE FUNCTION update_updated_at();
CREATE TRIGGER tr_news BEFORE UPDATE ON news
  FOR EACH ROW EXECUTE FUNCTION update_updated_at();
CREATE TRIGGER tr_careers BEFORE UPDATE ON careers_data
  FOR EACH ROW EXECUTE FUNCTION update_updated_at();
CREATE TRIGGER tr_equipment BEFORE UPDATE ON equipment
  FOR EACH ROW EXECUTE FUNCTION update_updated_at();
CREATE TRIGGER tr_timeline BEFORE UPDATE ON timeline_items
  FOR EACH ROW EXECUTE FUNCTION update_updated_at();
```

### 5.4 创建图片存储桶（后期上传用）

1. 进入 **Storage → New bucket**
2. Name：`media`
3. 设为 **Public bucket**

## 六、Phase 3：改代码接 Supabase

### 6.1 安装 / 移除依赖

```bash
npm install @supabase/supabase-js
npm uninstall @upstash/redis @vercel/kv redis
```

### 6.2 本地环境变量

在项目根目录创建 `.env.local`：

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGci...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGci...

# 管理端登录
ADMIN_USERNAME=admin
ADMIN_PASSWORD=你的强密码
ADMIN_SESSION_SECRET=随机32位以上字符串

# 站点
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

> **不再需要** Redis 相关变量：  
> `UPSTASH_REDIS_REST_URL`、`UPSTASH_REDIS_REST_TOKEN`、`KV_REST_API_URL`、`KV_REST_API_TOKEN`

### 6.3 代码改造清单

| 顺序 | 任务 | 说明 |
|------|------|------|
| 1 | 新建 `lib/supabase.ts` | Supabase 客户端 |
| 2 | 重写 `/api/careers` | 读写 `careers_data` 表，去掉 Redis |
| 3 | 新建 `/api/auth/login` | 服务端登录 |
| 4 | 改 `middleware.ts` | 保护 `/admin` 和写操作 API |
| 5 | 新建 `/api/news` | 新闻 CRUD |
| 6 | 新建 `/api/content/*` | 页面内容 API |
| 7 | 改前台页面 | 从 API 读数据，保留 fallback |
| 8 | 扩展管理端 | Dashboard + 各模块管理页 |

### 6.4 管理端模块规划

```
/admin
├── login          # 登录
├── dashboard      # 总览
├── site           # 站点设置（联系信息、SEO）
├── home           # 首页内容
├── about          # 关于我们
├── mission        # 实力见证 / 时间轴
├── equipment      # 装备清单
├── news           # 新闻管理
├── careers        # 招聘管理
└── media          # 图片上传（后期）
```

### 6.5 数据迁移（一次性）

| 数据来源 | 导入目标表 |
|----------|------------|
| `data/careers.json` | `careers_data` |
| `lib/newsData.ts` | `news` |
| `messages/zh.json` + `en.json` | `page_sections` / `site_settings` |
| `lib/site.ts` | `site_settings` |
| 使命页时间轴（代码内） | `timeline_items` |
| 装备清单（代码内） | `equipment` |

图片初期可继续使用 `public/` 目录，不必立即迁移到 Supabase Storage。

## 八、Phase 5：Vercel 部署

### 8.1 导入项目

1. 登录 [vercel.com](https://vercel.com)
2. **Add New → Project**
3. 选择 GitHub 仓库 `wintex-logistics`
4. 配置：
   - **Framework Preset**：Next.js（自动识别）
   - **Root Directory**：若项目在子目录则填 `company-site-template-main`
   - **Build Command**：`npm run build`（默认）

### 8.2 配置环境变量

在 Vercel **Environment Variables** 中添加（勾选 Production、Preview、Development）：

```env
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
SUPABASE_SERVICE_ROLE_KEY=eyJ...
ADMIN_USERNAME=admin
ADMIN_PASSWORD=你的强密码
ADMIN_SESSION_SECRET=随机32位以上字符串
NEXT_PUBLIC_SITE_URL=https://你的项目.vercel.app
```

### 8.3 部署

点击 **Deploy**，等待 2–5 分钟。  
部署成功后访问：`https://wintex-logistics.vercel.app`（以实际域名为准）

## 九、Phase 6：绑定自定义域名（可选）

1. Vercel 项目 → **Settings → Domains**
2. 添加域名，例如 `www.wintex.com.ph`
3. 在域名 DNS 服务商处按 Vercel 提示添加 CNAME / A 记录
4. 更新环境变量 `NEXT_PUBLIC_SITE_URL` 为正式域名
5. 重新 Deploy
